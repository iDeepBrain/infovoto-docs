# Manual de Usuario — InfoVoto Perú 2026

InfoVoto es un sistema de chatbot inteligente para las **Elecciones Generales Perú 2026**.
Responde preguntas sobre candidatos, planes de gobierno, locales de votación y más,
utilizando datos oficiales del JNE y ONPE.

---

## ¿Qué puedes consultar?

| Categoría | Ejemplos de preguntas |
|-----------|----------------------|
| **Candidatos** | "¿Quién es el candidato con DNI 12345678?" |
| **Planes de gobierno** | "¿Qué propone Fuerza Popular sobre seguridad?" |
| **Comparar partidos** | "Compara las propuestas de salud de APP y el Partido Morado" |
| **Mi local de votación** | "¿Dónde me toca votar con DNI 87654321?" |
| **Miembro de mesa** | "¿Fui sorteado como miembro de mesa?" |
| **Multas** | "¿Tengo multas electorales pendientes?" |
| **Candidatos excluidos** | "¿Qué candidatos fueron excluidos por el JNE?" |
| **Financiamiento** | "¿Cuánto ha recaudado Alianza para el Progreso?" |
